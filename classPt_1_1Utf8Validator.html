Detailed Description

Utf8Validator checks that a byte sequence is well-formed UTF-8 as defined by RFC 3629. Bytes may arrive in chunks; a character may be split across feeds. Overlong encodings, surrogate code points and values above U+10FFFF are rejected. After an error, further feeds fail until reset().

Pt::Utf8Validator v;
v.advance(part1, n1);
v.advance(part2, n2);
if( ! v.finish() )
{
// incomplete or ill-formed
}
