Detailed Description

An EventSink accepts events from an EventSource or from direct calls. commitEvent() queues an event and starts processing. queueEvent() queues without starting processing, so several events can be added first. wake() starts processing.

EventLoop is an EventSink. Events queued for a loop are delivered on eventReceived in the loop thread.
