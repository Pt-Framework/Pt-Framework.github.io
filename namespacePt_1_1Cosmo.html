Detailed Description

The Cosmo component model allows to assemble programs from several components. Each component implements one or more interfaces and may depend on one or more interfaces of other components. The component manager of the Cosmo application is used to create components and to resolve dependencies between them. In order to create a component, the according component plugin has to be impemented.
