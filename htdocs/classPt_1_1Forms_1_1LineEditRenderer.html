Detailed Description

A LineEditRenderer is a Style::Facet for the line-edit family. Named measure methods run inside-out. Named layout methods run outside-in. Named render methods paint prepared rectangles. The widget owns geometry and orchestrates those passes. The renderer does not mutate widget geometry.

Derive a renderer to change the look of line edits. Register it on a Style, or assign it to a widget with LineEdit::setRenderer().
