Core Module

Detailed Description

The core module is the basis for all other modules of the framework. It has no dependency on any system specific libraries except the standard C++ library. Applications and other modules build on the areas covered by the core module:

  • Basic Types provides program options, application settings, a type-safe event base class and a few general-purpose helper types.
  • Fixed-Size Integers provides fixed-size, platform-independent integer types.
  • Dates and Times provides durations and points in calendar time.
  • Atomic Operations provides lock-free atomic integer and pointer operations.
  • Coroutines provides cancellable, co_await-able tasks and lazily produced value sequences.
  • Allocators provides custom allocation strategies for optimized memory management.
  • Text Processing extends the string and localization support of the C++ standard library to work with unicode characters, strings, encodings and regular expressions.
  • Signals and Delegates provides a type-safe callback mechanism for connecting signals to slots and delegates.
  • Type Traits and Information provides compile-time type traits and runtime type information.
  • Conversions provides conversion between strings, numbers and byte orders.
  • Serialization composes and decomposes types to text or binary formats.
