87
88 Construct the socket with the %Client that performs the
89 handshake. Connect %connected() and call %beginConnect() with a
90 request path, or with a %ws:// URL whose host and port are
91 already the client's endpoint. The path and query of that URL
92 become the request URL; the client does not take the host from
93 the URL. The optional second argument is the Origin header.
94 %endConnect() completes the handshake and throws if it failed.
95 After that success the socket no longer uses the client for
96 messages.
97
98 The socket owns two %WebSocketMessage objects, %incoming() and
99 %outgoing(), the way a client owns a request and a reply. Set
100 the type, write the body, and call %beginSend(). %outputReady()
101 reports that data bytes were sent. %endSend() returns
102 %MessageProgress. If the send is not finished, %beginSend()
103 continues the same message. %beginReceive() fills %incoming().
104 %inputReady() reports that data bytes were received.
105 %endReceive() returns progress. After %finished(), %clear()
106 drops the body so the same object can carry the next message.
107
108 Ping, pong and close are socket operations, not messages.
109
110 @code
111 socket.ping();
112 socket.close(1000, "done");
113 @endcode
114
115 %ping() enqueues a ping. A received ping is answered by the
116 engine. A received pong is consumed. Neither is delivered
117 through %incoming(). %close() enqueues a close frame with a
118 status code and a reason. A received close is answered by the
119 engine. %closeCode() and %closeReason() report the handshake
120 that ended the stream. %closed() is emitted while this socket
121 is still alive. The stream has already cleared its session
122 pointer. Peer close, an I/O error, a close frame and
123 destruction of the stream all emit it. It ends an outstanding
124 send or receive. The owner deletes this socket.
125
126 On the server the application does not construct this type. The
127 server facade is %WebSocketSession, which exposes the same
128 message operations without a client handshake.
